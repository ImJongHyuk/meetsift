# 모델·공급자 설정

앱 상단의 **모델·공급자 설정**에서 전사, 화자 분리, 회의록을 각각 설정합니다. 설정 저장 후 시작하는 작업부터 적용되며, 실행 중인 작업은 시작 당시의 설정을 사용합니다. 기본값은 로컬 전사·화자 분리와 로컬 회의록 서버입니다. 회의록 모델은 설정에서 선택하세요. ChatGPT 공급자는 별도 확장을 설치한 경우에 사용할 수 있습니다.

## 로컬 GPU

- 전사: MOSS 또는 Whisper INT8을 전사문의 모델 메뉴에서 선택합니다. 설정의 모델 폴더 경로를 비우면 기존 `MEETING_MOSS_MODEL` / `MEETING_WHISPER_MODEL`을 사용합니다. 모델을 바꾸면 사용자 지정 경로도 그 모델에 맞춰야 합니다.
- 화자 분리: Nemotron을 사용합니다. 모델 폴더 경로를 비우면 `MEETING_DIAR_MODEL`을 사용합니다.
- Python·CUDA·모델 설치는 기존 Windows/WSL2 안내대로 필요합니다. 경로는 Windows 앱이 아닌 **백엔드가 실행되는 기기** 기준입니다.
- 회의록: Ollama·vLLM 등 로컬 GPU 모델 서버를 별도로 실행하고 OpenAI 호환 주소(예: `http://127.0.0.1:11434/v1`)와 모델 ID를 입력합니다. 앱은 회의록 LLM을 직접 설치하거나 서빙하지 않습니다.

## 외부 서버

각 단계에 서버의 API 기본 주소, 모델 ID, API 키를 입력합니다. 인증이 없는 자체 서버는 API 키를 비워둘 수 있습니다. 같은 주소라도 단계마다 다른 모델·키를 지정할 수 있습니다.

- 전사: 기본 경로 `/audio/transcriptions`에 `file`, `model`, `language=ko`, `response_format=verbose_json`을 multipart로 전송합니다. `segments: [{start,end,text}]` 또는 타임스탬프가 있는 `words`를 반환해야 합니다. 텍스트만 반환하는 모델은 시간 정보를 만들지 않고 오류로 안내합니다.
- 화자 분리: 기본적으로 같은 전사 API를 사용하며, `segments` / `words`의 `speaker` 또는 `speaker_id` / `speaker_label`을 읽습니다. 별도 화자 API는 세부 설정에서 API 경로를 바꾸고 `turns: [{start,end,speaker_id}]` 형태로 반환할 수 있습니다. OpenAI 방식 화자 모델에는 `diarized_json` 응답 형식을 선택할 수 있습니다.
- 회의록: `/chat/completions`에 모델, 규칙과 전사문을 보내고 텍스트 응답을 저장합니다. 취소 버튼은 진행 중인 요청을 취소합니다.
- 연결 확인은 `/models`의 목록을 확인합니다. 해당 경로를 제공하지 않는 사용자 지정 음성 서버는 이 확인에 실패할 수 있으며, 실제 추론 호출은 별개입니다. 로컬 음성은 API 서버 연결만 확인합니다.

## OpenRouter

API 기본 주소는 `https://openrouter.ai/api/v1`입니다. 다른 호스트는 외부 서버 공급자를 사용하세요. 각 단계에서 OpenRouter를 선택하면 공식 API의 최신 모델 목록을 불러옵니다. 모델 이름이나 ID로 검색한 뒤 목록에서 선택하고 API 키를 입력하세요. 모델 ID 목록이나 기본 모델을 앱에 고정하지 않습니다.

- 전사·화자 분리: `/models?output_modalities=transcription`에서 음성 입력·전사 출력 모델을 조회합니다. 타임스탬프를 지원하는 STT 모델이 필요합니다. 목록 자체는 `verbose_json`이나 화자 분리 지원을 보장하지 않습니다.
- 화자 분리 옵션: `microsoft/mai-transcribe-2`에는 `azure.diarization.enabled`, `elevenlabs/*`에는 `elevenlabs.diarize`, `deepgram/*`에는 `deepgram.diarize`를 자동 적용합니다. 다른 모델은 해당 공급자의 옵션 JSON을 직접 설정해야 합니다. 일반 채팅 모델을 화자 분리 모델로 사용할 수는 없습니다.
- 회의록: `/models?output_modalities=text`에서 텍스트 입력·출력 모델만 표시합니다.
- 목록은 Electron 메인 프로세스에서 API 키 없이 조회하는 공개 카탈로그입니다. 동일 종류의 동시 조회는 합치고 5분 동안 메모리에 캐시합니다. **새로고침**은 캐시 유효 시간과 관계없이 재조회합니다. 실제 모델 사용 권한·잔액·계정 정책은 별도이며 연결 확인과 실제 요청에 해당 단계의 키를 사용합니다.
- 조회 실패 시 마지막으로 받은 목록과 현재 선택을 유지하고 실패를 표시합니다. 앱을 다시 실행하면 목록을 새로 조회합니다. 저장된 모델이 목록에서 사라져도 자동으로 다른 모델로 교체하지 않고 **현재 설정 · 목록에서 확인되지 않음**으로 표시합니다. 검색어를 바꿔도 선택은 유지됩니다.

[OpenRouter STT 계약](https://openrouter.ai/docs/guides/overview/multimodal/stt)에 맞춰 음성을 전송하며, 화자 ID나 타임스탬프가 없는 응답은 임의 보완하지 않습니다. 원격 음성은 최대 300초 단위로 요청하고, 구간별 시간을 원본 시간으로 변환합니다. 청크가 나뉜 경우 화자 ID도 구간별로 분리합니다. 서로 다른 구간의 같은 번호가 같은 사람이라는 보장은 하지 않으며, 청크 경계와 화자 연결은 원음으로 검토해야 합니다.

## 데이터·API 키

외부 전사·화자 분리 공급자에는 음성이, 외부 회의록 공급자에는 전사문·화자·시간·작성 규칙이 전달됩니다. API 키는 Electron 메인 프로세스에서 OS `safeStorage`로 암호화해 사용자 앱 데이터의 `provider-settings.json`에 저장합니다. 저장한 키는 화면으로 다시 반환하지 않으며, 새 키로 교체하거나 지울 수 있습니다. 주소나 공급자를 바꾸면 기존 키는 새 목적지에 자동 전달하지 않습니다.

음성 키는 인증된 로컬 백엔드에 해당 작업을 위해 전달하고 메모리와 작업자 표준입력에서만 사용합니다. 작업 JSON·로그·내보내기에는 저장하지 않습니다. 앱·백엔드 재시작으로 중단된 작업은 기존과 같이 다시 가져와야 합니다.

## 갤럭시 M4A 가져오기

Windows 앱은 명시적인 **음성·동영상**, **갤럭시 음성 녹음 (M4A)**, **모든 파일** 필터를 제공합니다. 마지막으로 선택한 폴더를 기억하며 첫 실행은 다운로드 폴더에서 시작합니다. 브라우저 개발 화면의 HTML 파일 입력과는 다른 Electron 기본 대화상자입니다.

Windows의 알려진 파일 확장자 숨김 설정이 켜져 있으면 기본 대화상자의 목록에서 `.m4a` 같은 접미사가 생략될 수 있습니다. 앱의 M4A 필터는 그대로 적용되며, 선택 후 앱에는 전체 파일 이름이 표시됩니다. 앱은 Windows의 전역 확장자 표시 설정을 변경하지 않습니다.

갤럭시 음성 녹음은 일반적으로 `내 파일 → 내장 메모리 → Recordings → Voice Recorder` 아래의 `.m4a` 파일입니다. USB 연결이나 공유 기능으로 파일을 먼저 PC로 복사한 뒤 그 폴더에서 선택하세요. 폴더가 비어 보이면 현재 위치와 선택된 파일 형식을 확인하고 모든 파일 필터를 사용할 수 있습니다. 휴대폰의 녹음이 PC에 자동 동기화되는 것은 아닙니다.

M4A/AAC 원본은 그대로 보존하고 FFmpeg가 별도의 16 kHz 모노 WAV로 변환합니다. 한글·공백·대문자 `.M4A` 이름을 지원하며, 원음에는 `audio/mp4` 형식을 지정합니다. 확장자만 바꾼 손상 파일이나 음성 트랙이 없는 파일은 전사할 수 없습니다.

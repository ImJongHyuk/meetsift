# MeetSift — 화면 규칙

흰색 배경, 구분선만 있는 3열 작업 공간. 왼쪽 파일 목록 19%, 가운데 전사문 46%, 오른쪽 회의록 35%. 헤더 72px, 하단 처리 안내. 기본 글꼴 system-ui / 맑은 고딕, 제목 22px 650, 본문 15px, 보조 13px. 본문 #171b22, 보조 #7b8392, 구분선 #dce0e7, 강조 #192e59. 버튼/입력 반경 5px. 패널 여백 26px. 작은 화면은 세로 순서로 연결.

빈 상태에는 실제 파일/결과만 표시한다. 원음 플레이어, 시간 이동, 화자 이름, 전사문 수정, 겹침과 검토 표시가 가운데에 배치된다. 회의록 작성 규칙과 모델 선택·생성·내보내기는 오른쪽에 배치한다. 상태/오류/선택은 실제 서버 결과만 반영한다.
